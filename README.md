## 🚀 Como executar o projeto

### Pré-requisitos

Node.js
npm

### Instalação
Clone o repositório:
```
git clone https://github.com/MilenaMP/portfolio.git
```

Entre na pasta:
```
cd portfolio 
```

Instale as dependências:
```
npm install 
```

Execute o projeto:
```
npm run dev 
```

> A aplicação estará disponível no endereço exibido pelo Vite no terminal.
